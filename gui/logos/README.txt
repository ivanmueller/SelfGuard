SelfGuard — site logos
======================

Drop official logo image files here, named by site. The build embeds whatever is
present; sites without a file fall back to the coloured monogram tile.

Expected filenames (any of .png .jpg .webp .svg .gif):
  reddit.*   instagram.*   x.*   facebook.*   tiktok.*   youtube.*   pinterest.*

The base filename (lowercased, minus extension) is matched to the site by
dropping the domain suffix — e.g. "reddit.com" -> "reddit". So "reddit.png"
labels the Reddit tile, "x.jpg" labels the X tile, and so on.

Square images work best (they're shown in a rounded tile, object-fit: contain).

These are third-party brand logos/trademarks — supply your own copies and follow
each brand's usage guidelines. They are not distributed with this project.
